📜 移动端系统 — 更新历史

v2.7.1

  • 登录速度大幅优化：封禁检查、用户查询、密码哈希三请求并行执行
  • 用户查询改用 ilike 单次大小写不敏感匹配，消除冗余网络请求
  • 封禁设备列表增加60秒缓存，减少重复网络请求
  • IP获取和登录记录改为完全非阻塞，不延迟用户界面响应
  • 添加 preconnect 预连接，提前建立TCP/TLS连接
  • 过期数据清理延迟5秒执行，避免与登录请求竞争网络带宽

v2.7.0

  • 用户名支持中文、emoji及特殊符号，按Unicode码点计算长度（1-20字符）
  • 注册、后台单个添加、批量添加均接入统一用户名校验
  • 禁止用户名包含空格和控制字符，提升数据安全性

v2.6.7

  • 回忆录编辑功能从后台移至查看页面，支持直接在查看界面编辑
  • 编辑模式支持：编辑时间/标题/内容、插入图片、B站视频、节点排序、添加新节点
  • 删除背景图片和字体样式编辑功能
  • 首页"探索时光记忆"按钮固定底部，诗句文字自动向上滚动
  • 时间节点滑动每次仅切换一个节点，避免跳过
  • 授予回忆录编辑权限时自动授予查看权限

v2.6.6

  • 新增回忆录权限系统：分为"查看"和"编辑"两种权限
  • 非管理员用户默认授予回忆录查看权限，管理员默认授予编辑权限
  • 后台可批量或单独管理用户的回忆录查看/编辑权限
  • 无查看权限的用户无法进入回忆录页面
  • 后台回忆录管理仅对拥有编辑权限的管理员可见

v2.6.5

  • 修复未登录用户直接访问 /history 可进入回忆录的安全漏洞

v2.6.4

  • 每次打开移动端时自动清理过期数据：手机验证码、邮箱验证码、密码重置链接、超过90天的通知历史

v2.6.3

  • 优化课间休息显示逻辑：跨下课项目的完成时间分三行显示（第一段时间、☕ 课间休息、第二段时间）
  • 无跨下课项目时，课间休息作为独立行显示在前后两项作业之间

v2.6.2

  • 回忆录预制内容自动写入数据库，可在后台修改或删除

v2.6.1

  • 修复"情怀"按钮未经过回忆录权限检查直接跳转的问题
  • 修复验证码存储时email字段null约束违规问题

v2.6.0

  • 后台回忆录时间节点管理升级为卡片式展示，支持富文本编辑器
  • 富文本编辑器支持：字体、字号、字色、对齐、加粗、斜体、下划线
  • 支持插入图片（可带超链接）、超链接文字、超链接按钮（可设置形状、颜色、位置）
  • 支持搜索并嵌入B站视频（可输入关键词搜索或直接粘贴BV号）
  • 每个时间节点可设置独立背景图片
  • 回忆录页面渲染支持富文本HTML内容，兼容旧版纯文本数据
  • 预加载阶段增加富文本内嵌图片和背景图片的预加载

v2.5.0

  • 回忆录页面新增BGM背景音乐系统：50首主题音乐随机播放，支持淡入淡出、音符图标控制、视频联动
  • 回忆录加载阶段预加载所有图片和视频资源
  • 回忆录时间节点数据存储到Supabase数据库，支持多设备同步
  • 登录后检测默认密码强制修改
  • 学生注册时提示真实姓名涉及后期权限授予
  • 修复验证码存储兼容性问题

v2.4.0

  • 新增 Netlify Function 反向代理：所有 Supabase 请求经由 Netlify 服务器中转，大幅提升国内访问速度和稳定性
  • 移除前端 Supabase API Key 暴露，认证逻辑移至服务器端，增强安全性

v2.3.2

  • 修复登录时「Failed to fetch」错误：Supabase 连接失败时自动回退到本地模式登录
  • 优化错误提示信息，网络异常时引导用户重试

v2.3.1

  • 发送历史每条右侧新增红色圆形删除按钮（白色垃圾桶图标），点击即可删除单条记录
  • 发送历史底部新增「删除全部通知历史」按钮，点击需确认后清空所有记录

v2.3.0

  • 时间表数据优先从 Supabase 数据库获取，每 5 秒静默轮询更新
  • ntfy.sh SSE 保留为数据库不可用时的备用接收方式
  • 修改请求优先写入数据库 modify_requests 表，支持审批状态追踪
  • 新增 45 秒轮询修改请求状态：approved 自动刷新时间表，ignored 提示用户
  • 数据库操作失败时自动回退到 ntfy.sh，保证服务可用性

v2.2.0

  • 邮件发送从 SmtpJS 迁移到 EmailJS SDK，不再暴露 SMTP 密码
  • 密码重置邮件模板优化：自定义背景图、黑体字体、粉色按钮
  • 邮箱验证忽略大小写，用户名全局忽略大小写匹配
  • 新增申诉系统：邮件发送失败时用户可提交申诉信息（用户名、真实姓名、备注）
  • 后台新增"申诉处理"功能：管理员可查看申诉并直接重置用户密码
  • 新增登录记录功能：记录每次登录的 IP、设备信息和时间
  • 个人中心展示登录记录卡片，管理员可从记录中封禁 IP 或设备
  • 后台新增"封禁设备"管理功能（仅查看/删除，不可手动添加）
  • 后台单用户添加改造：按钮式选择身份、学科下拉选择（含自定义选项）
  • 用户管理操作按钮突出显示：蓝色背景（编辑）、红色背景（删除）、白色文字
  • 管理员后台支持 /admin 路径访问（Netlify 重定向）
  • 新增全屏加载遮罩，页面初始化完成后淡出显示
  • 首次登录或密码被管理员重置后强制修改密码

v2.1.0

  • 数据存储层重构：从 localStorage 迁移到 Supabase 云端数据库，支持多设备数据同步
  • 引入统一数据访问层 DB 对象，所有用户操作函数通过 DB 接口访问数据
  • 实现双模式架构：Supabase 模式（云端）和 localStorage 回退模式（本地），不可用时自动回退
  • 新增建表 SQL 注释（users 表、verify_codes 表），含索引和 RLS 策略
  • 本地会话缓存（登录状态、发送历史）继续使用 localStorage
  • IP 封禁数据存储在管理员用户记录的 banned_ips 字段中（Supabase 模式）
